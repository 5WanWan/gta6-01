PORT MERIDIAN — Sun Coast Getaway: an original open-world crime game in the spirit of GTA 6, built for make.fun's "Make GTA 6" bounty. Explore the sun-soaked coastal city of Port Meridian on foot and by car, steal cars, outrun the police across five wanted levels, take on five story missions for fixer Marla Quinn, fight Venn's crew, and save your progress. No libraries, no network requests — plain static files, keyboard and mouse.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
